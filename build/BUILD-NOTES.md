# Build notes — Morning Scroll repository additions (2026-11-14)

- `morning-post/build_edition_page.py` — builds one Morning Scroll edition page (edition-YYYY-MM-DD.html) from the night's gathered pieces: weather, local news, standing sections, and the story list with its seven-button player. It runs on Muse's side as part of the nightly Scroll job; the finished page is what this repository publishes. It stands beside the build chain that already lives in this repository (morning-post/batch/: build_and_manifest.py, chain_gate.py, verify.py, publish.py, archive_update.py, weather_pull.py, ledger_verify.py, yard_verify.py) and build_paper.py at the root.
- `build/stewards-ledger-build-2026-11-11.py` — the Steward's Ledger is built by a dated build program, one per edition, kept in the ledger goal's working files on Muse's side; this is the newest one standing (Edition 34's line descends from it). The Ledger's finished pages stand in this repository. A new edition starts by copying the newest dated build and adjusting it.
